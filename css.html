Apa Itu CSS?

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan elemen HTML. Dengan CSS, Anda dapat mengatur warna, font, layout, dan banyak lagi.

CSS membantu memisahkan konten (HTML) dari tampilan sehingga membuat halaman web lebih mudah dikelola dan diperbarui.

Menambahkan CSS ke HTML

Ada tiga cara menambahkan CSS ke dokumen HTML:

  1. Inline CSS: Langsung di atribut elemen HTML.
  2. Internal CSS: Di dalam elemen <style> di bagian <head>.
  3. External CSS: Menggunakan file terpisah dengan ekstensi .css.
Contoh Inline CSS: 
<p style="color: red;">Teks berwarna merah</p>
Contoh Internal CSS: 
<style>
p {
color: blue;
}
</style>
Contoh External CSS: 
<link rel="stylesheet" href="styles.css">

Selektor dalam CSS

Selektor digunakan untuk memilih elemen HTML yang ingin diberi gaya.

  • Selektor Universal: * - Memilih semua elemen.
  • Selektor Tag: p - Memilih semua elemen <p>.
  • Selektor Class: .nama-class - Memilih elemen dengan atribut class tertentu.
  • Selektor ID: #nama-id - Memilih elemen dengan atribut id tertentu.
  • Selektor Grup: h1, h2, p - Memilih beberapa elemen sekaligus.
Contoh Selektor Class: 
.highlight {
background-color: yellow;
font-weight: bold;
}

Properti CSS Dasar

Beberapa properti dasar dalam CSS:

  • color: Mengatur warna teks.
  • background-color: Mengatur warna latar belakang.
  • font-size: Mengatur ukuran teks.
  • font-family: Mengatur jenis huruf.
  • margin: Mengatur jarak luar elemen.
  • padding: Mengatur jarak dalam elemen.
  • border: Mengatur batas elemen.
Contoh: 
h1 {
color: blue;
background-color: lightgray;
font-size: 24px;
padding: 10px;
border: 2px solid black;
}

Model Box CSS

Setiap elemen HTML dapat dianggap sebagai sebuah kotak yang terdiri dari:

  • Content: Isi dari elemen (teks, gambar, dll).
  • Padding: Ruang di sekitar konten.
  • Border: Batas di sekitar padding (opsional).
  • Margin: Ruang di luar border.
Contoh Model Box: 
.box {
width: 200px;
padding: 20px;
border: 5px solid black;
margin: 10px;
}

Tips dan Trik

  • Gunakan developer tools di browser untuk memeriksa elemen dan menguji CSS secara langsung.
  • Gunakan CSS-Tricks untuk referensi dan tutorial.
  • Jangan lupa menambahkan komentar dalam kode CSS Anda untuk mempermudah pemahaman.
