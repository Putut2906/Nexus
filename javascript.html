Belajar JavaScript

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web lebih interaktif. Berikut ini adalah materi dasar untuk belajar JavaScript:

1. Menampilkan Output

Kode JavaScript dapat dijalankan di browser menggunakan konsol, file eksternal, atau langsung di dalam HTML menggunakan tag <script>.

// Cara menampilkan output di JavaScript
console.log('Hello, world!'); // Menampilkan di konsol
alert('Hello, world!');      // Menampilkan pop-up

2. Variabel

Variabel digunakan untuk menyimpan data. JavaScript memiliki tiga cara untuk mendeklarasikan variabel: var, let, dan const.

// Deklarasi variabel
let nama = 'Putut';
const umur = 25;
var kota = 'Jakarta';

3. Tipe Data

JavaScript mendukung beberapa tipe data seperti:

  • String: "Halo Dunia"
  • Number: 123, 4.56
  • Boolean: true, false
  • Array: [1, 2, 3]
  • Object: { nama: 'Putut', umur: 25 }

4. Fungsi

Fungsi adalah blok kode yang dapat digunakan kembali. Fungsi dideklarasikan menggunakan kata kunci function.

// Fungsi sederhana
function sapa(nama) {
return `Halo, ${nama}!`;
}

console.log(sapa('Putut'));

5. Event Handling

JavaScript dapat digunakan untuk menangani berbagai event seperti klik tombol.

// Contoh Event Handling

6. DOM Manipulation

Document Object Model (DOM) memungkinkan JavaScript untuk memodifikasi struktur HTML.

// Mengubah teks pada elemen HTML
const heading = document.querySelector('h1');
heading.textContent = 'Belajar JavaScript itu Seru!';

7. Looping

Gunakan for, while, atau do-while untuk melakukan iterasi.

// Contoh looping
for (let i = 0; i < 5; i++) {
console.log(`Iterasi ke-${i}`);
}

8. Kondisional

Gunakan if, else, atau switch untuk membuat logika percabangan.

// Contoh kondisional
let umur = 18;
if (umur >= 18) {
console.log('Anda sudah dewasa');
} else {
console.log('Anda masih anak-anak');
}
