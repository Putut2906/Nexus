Pengertian HTML

HTML, singkatan dari HyperText Markup Language, adalah bahasa markup standar yang digunakan untuk membuat dan menyusun halaman web. HTML bukan bahasa pemrograman karena tidak memiliki logika pemrograman seperti variabel atau fungsi, melainkan merupakan bahasa markup yang digunakan untuk mengatur struktur dan elemen-elemen dalam dokumen web.

HTML digunakan untuk mendefinisikan struktur konten pada halaman web. Setiap elemen HTML ditulis menggunakan tag, yang biasanya memiliki bentuk seperti ini: .... Tag terdiri dari tanda kurung sudut (< >) dan nama elemen, serta biasanya diikuti oleh konten atau atribut tertentu.

Secara keseluruhan, fungsi HTML adalah membangun struktur dasar dari halaman web, menampilkan konten, dan memungkinkan integrasi dengan teknologi lainnya. Tanpa HTML, halaman web modern tidak dapat dibuat atau ditampilkan di browser. Sebagai bahasa markup standar, HTML adalah fondasi untuk pengembangan web yang lebih lanjut.

Struktur Dasar HTML

Struktur dasar HTML adalah rangkaian elemen yang membentuk halaman web. Setiap elemen memiliki tujuan tertentu dan ditulis dalam format tag. Berikut adalah penjelasan lengkap tentang struktur dasar HTML:

HTML
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman</title>
    <link rel="stylesheet" href="styles.css">
    <script src="script.js"></script>
  </head>
  <body>
    <header>
      <h1>Selamat Datang di Halaman Web</h1>
      <nav>
        <ul>
          <li><a href="#home">Home</a></li>
          <li><a href="#about">About</a></li>
          <li><a href="#contact">Contact</a></li>
        </ul>
      </nav>
    </header>
    <section>
      <h2>Konten Utama</h2>
      <p>Ini adalah paragraf pertama dari konten utama halaman web.</p>
    </section>
    <footer>
      <p>&copy; 2025 Nama Perusahaan. All rights reserved.</p>
    </footer>
  </body>
</html>
  • <!DOCTYPE html>Ini adalah deklarasi tipe dokumen yang memberi tahu browser bahwa dokumen ini adalah HTML5.
  • <html> Elemen ini merupakan elemen root dari sebuah halaman web. Semua elemen HTML lainnya akan berada di dalam elemen <html>
  • <head> Bagian ini berisi informasi metadata tentang halaman, seperti judul halaman, penghubung ke file CSS, skrip JavaScript, dan informasi lainnya yang tidak ditampilkan langsung di halaman web. Beberapa tag dalam bagian <head> meliputi:
    1. <title> Menentukan judul halaman yang muncul di tab browser.
    2. <meta> Memberikan informasi tentang karakter encoding atau deskripsi halaman.
    3. <link> Menghubungkan file eksternal, seperti file CSS.
    4. <script> Menyisipkan kode JavaScript
  • <body> Bagian ini berisi konten yang akan ditampilkan di halaman web. Semua elemen yang terlihat oleh pengguna berada di dalam elemen <body>, seperti teks, gambar, tabel, dan formulir. Struktur Konten dalam <body> ada berbagai elemen yang dapat digunakan untuk menyusun konten halaman. Beberapa elemen dasar yang sering digunakan
    1. <h1> hingga <h6>Tag header untuk membuat judul, dengan <h1> sebagai yang terbesar
    2. <p> Digunakan untuk paragraf.
    3. <a> Untuk membuat hyperlink
    4. <img> Menyisipkan gambar.
    5. <ul>, <ol>, dan <li> : Untuk membuat daftar tidak berurutan (unordered list) atau berurutan (ordered list).
    6. <div> Digunakan untuk membungkus atau mengelompokkan elemen-elemen lainnya.
    7. <span> Digunakan untuk membungkus elemen inline, seperti teks.

Elemen HTML Penting

HTML terdiri dari elemen-elemen yang dibuka dengan tag pembuka dan diakhiri dengan tag penutup (kecuali elemen tertentu). Contoh:

<p>Ini adalah sebuah paragraf.</p>

Berikut adalah elemen penting dalam HTML:

  • <h1> hingga <h6>: Untuk heading atau judul. Heading <h1> adalah yang terbesar, sedangkan <h6> adalah yang terkecil.
  • <p>: Untuk membuat paragraf.
  • <a>: Untuk membuat tautan. Contoh:
    <a href="https://www.example.com">Klik di sini</a>
  • <img>: Untuk menampilkan gambar. Contoh:
    <img src="gambar.jpg" alt="Deskripsi gambar">
  • <ul> dan <li>: Untuk membuat daftar tidak berurutan (bulleted list).
  • <ol> dan <li>: Untuk membuat daftar berurutan (numbered list).
  • <nav>: Untuk membuat navigasi di halaman web. Navigasi biasanya berisi tautan ke berbagai bagian atau halaman. Contoh:
    <nav>
      <a href="#home">Home</a>
      <a href="#about">About</a>
      <a href="#contact">Contact</a>
    </nav>
  • <div>: Elemen pembungkus (container) yang digunakan untuk mengelompokkan elemen-elemen lain. Elemen ini tidak memiliki gaya bawaan, tetapi sangat fleksibel untuk diatur dengan CSS. Contoh:
    <div class="konten">
      <p>Ini adalah paragraf di dalam div.</p>
      <img src="gambar.jpg" alt="Gambar di dalam div">
    </div>

Atribut HTML

Atribut memberikan informasi tambahan pada elemen HTML. Contoh atribut yang umum:

  • href: Menentukan tujuan tautan pada elemen <a>. Contoh:
    <a href="https://example.com">Tautan</a>
  • src: Menentukan sumber gambar pada elemen <img>. Contoh:
    <img src="gambar.jpg" alt="Gambar contoh">
  • alt: Menambahkan teks alternatif pada elemen <img>.
  • style: Menambahkan gaya langsung ke elemen. Contoh:
    <p style="color: red;">Teks merah</p>
